# GeoVoxel3D

## Unified 3D ULPIN & Vertical Property Mapping System

GeoVoxel3D is a 3D property mapping and visualization system designed to provide a simple and interactive view of buildings, blocks, roads, and property-related infrastructure.

## Features

- Interactive 3D map visualization
- Block and building selection
- Building and floor information
- Elevator visualization
- Pipeline visualization
- Spatial conflict visualization
- Property history information
- Search and filtering
- Interactive 3D controls

## Tech Stack

- React
- TypeScript
- Vite
- Three.js
- Tailwind CSS
